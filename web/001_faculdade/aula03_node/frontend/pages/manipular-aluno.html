Cadastro e edição de aluno

Esta página será utilizada para praticar requisições POST, GET /alunos/:ra e PUT.

Como usar

Para cadastrar, preencha os dados e clique em Salvar aluno.

Para editar, informe um RA existente e clique em Buscar aluno. Em seguida, altere os dados e salve.

Durante a aula, a lógica será implementada no arquivo aluno-formulario.js.
