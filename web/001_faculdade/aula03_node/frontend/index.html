Aula 09

Frontend consumindo API REST

Nesta aula, o frontend em HTML, CSS, Bootstrap e JavaScript passará a consumir a API de alunos criada com Node.js, TypeScript e Express.

As páginas já estão estruturadas visualmente. Durante a aula, serão implementadas as funções JavaScript responsáveis por buscar, cadastrar, editar e inativar alunos.

Ir para listagem Cadastrar aluno

Fluxo da aula

  1. Rodar o backend em localhost:3000.
  2. Abrir o frontend no navegador.
  3. Usar fetch para consumir a API.
  4. Renderizar os dados em uma tabela.
  5. Enviar dados do formulário para o backend.

GET

Buscar alunos na API e exibir na tela.

POST e PUT

Enviar dados do formulário para cadastrar ou atualizar.

DELETE lógico

Inativar alunos sem remover definitivamente do array.
